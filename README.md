\# TripMate – a group travel planner for students



A WPF desktop app (.NET 8) that helps students plan trips together, with a focus on

group travel and cost-splitting.



Planned features:

\- Day-by-day itinerary with route optimisation

\- Shared expense tracking that settles debts with the fewest transfers

\- Live weather, currency conversion and attraction search (free open APIs)

\- Spending charts and an ML.NET model that predicts the cost of a trip

\- Data stored with Entity Framework Core and SQLite



Work in progress. See the project board and commit history for who is working on what.
